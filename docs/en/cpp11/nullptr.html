nullptr in C++

Definition: In C++, a null pointer represents a pointer that does not point to any valid memory address.

From NULL and 0 to nullptr

In older versions of C++ before C++11, and in C, two common methods were used to represent a null pointer: 

int* ptr = 0;
int* ptr = NULL;

Problem: 0 and NULL are integer values rather than real pointer types. This may lead to ambiguity and difficult bugs when using function overloading. 

#include <iostream>

void foo(int value) {
    std::cout << "Function with int called\n";
}

void foo(int* pointer) {
    std::cout << "Function with pointer called\n";
}

int main() {
    foo(NULL);
}

nullptr in C++11

Starting with C++11, the nullptr keyword was introduced to solve this issue safely and explicitly.

  • Independent type: nullptr is a literal of type std::nullptr_t.
  • Type safety: It converts automatically to pointer types, but not to numeric types such as int or char. 
foo(nullptr);

Safe Usage

In modern C++, initialize a pointer with nullptr when it does not currently point to a valid object: 

int* myPointer = nullptr;

Check that the pointer is valid before dereferencing it:

if (myPointer != nullptr) {
    *myPointer = 10;
} else {
    // The pointer is null.
}

You can also use the shorter form:

if (myPointer) {
    *myPointer = 10;
}
